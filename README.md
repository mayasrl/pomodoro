# ⏱️ Timer Pomodoro com Sons Ambientes

Um timer Pomodoro minimalista e elegante com sons ambientes relaxantes para ajudar na concentração e produtividade.

## ✨ Funcionalidades

- **Timer Pomodoro Personalizável**: Configure os tempos de trabalho, pausa curta e pausa longa
- **Sons Ambientes**: 15 sons relaxantes para ajudar na concentração
  - Chuva, Floresta, Oceano, Lareira, Pássaros
  - Vento, Trovão, Riacho, Noite, Cafeteria
  - Ondas, Fogueira, Cachoeira, Grilos, Teclado
- **Tema Claro/Escuro**: Alterne entre os modos claro e escuro
- **Controle de Volume**: Ajuste o volume dos sons ou silencie
- **Interface Limpa**: Design minimalista e responsivo
- **Pet Virtual**: Acompanhante fofo durante suas sessões de estudo

## 🚀 Como Usar

1. **Acesse o site**: https://mayasrl.github.io/pomodoro/
2. **Configure o timer**: Ajuste os tempos de trabalho e pausas
3. **Escolha um som**: Clique em um dos sons ambientes
4. **Inicie o timer**: Clique em "Iniciar" e comece a trabalhar!

## 🎨 Temas

O timer possui dois temas:
- **Modo Escuro**: Ideal para trabalhar à noite
- **Modo Claro**: Perfeito para o dia

Clique no ícone de sol/lua para alternar entre os temas.

## 🎯 Técnica Pomodoro

A Técnica Pomodoro é um método de gerenciamento de tempo desenvolvido por Francesco Cirillo:

1. **Trabalhe por 25 minutos** (1 Pomodoro)
2. **Faça uma pausa de 5 minutos**
3. **Repita 4 vezes**
4. **Faça uma pausa longa de 15-30 minutos**

Este timer ajuda você a aplicar essa técnica de forma simples e eficaz!
